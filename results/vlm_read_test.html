  • 4 exists now. The old run produced none, on any field, across 24,516 calls. Every field here can reach it.
  • The floor lifted. Greenery fields sat at 1.44 and 1.80 because the two-anchor prompt gave the model nothing between "none at all" and "filling the view". Named rungs let it say "scattered canopy over part of the frontage" instead of rounding down to nothing.
  • Spread is the column to watch. A field's sd is how much it can discriminate between streets; a term with no spread contributes nothing to the index however well it correlates. Green in the last column means the new read spreads wider, red means narrower.
  • facade_variation is still the problem field — 88% on one value here, and the least confident field in every test we have run. It carries 22% of the index and has no measured counterpart.

What is stored

Nine fields × ten columns = 90, plus identity. Every read is derivable from what is on disk, so no future decision about how to summarise an answer needs another pass over the corpus.

field the survey answer, round(EV), an integer 1-7 field_ev the expected value, continuous field_argmax the tallest bar, what generate() would write field_p1 .. p7 the whole distribution

Runtime is 4.93 s per image against 5.18 s for the old generate() path — reading logits skips the generation loop, so a full rerun would finish faster than the 3.7 hours already spent.
