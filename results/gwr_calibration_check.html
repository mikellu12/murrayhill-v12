GWR Calibration Check

Four equations, four things that must hold. The regression itself cannot run — it needs an outcome this study does not have — but every precondition that does not involve the outcome is testable now, and all three pass on 681 nodes.

blocked on t_base — not on the frame, the geometry or the dimensions

1 · the regression

ln(tbase)=β0⁢(s)+βImg⁢ln⁢I+βId⁢ln⁢Y+βDep⁢ln⁢D+ε the Cobb-Douglas in logs. The exponents a, b, c ARE these slopes — that is the whole trick

Needs: the three regressors to be separable. If ln I, ln Y and ln D move together, no quantity of dwell data can tell βImg from βId.

2 · the local solve

β(s)=(XTWX)−1XTWY weighted least squares, run once per node — 681 regressions, not one

Needs: X⁠TWX invertible and well conditioned at every node. Above about 106 the local coefficients are numerically unstable — small changes in t_base swing them, and what looks like spatial variation is arithmetic noise.

3 · the kernel and its bandwidth

Wij=e−0.5(dijb)2 Gaussian on network distance, bandwidth b cross-validated

Needs: enough effective observations per fit for four parameters. A Gaussian has no hard edge, so what counts is the effective sample size, (Σw)² / Σw², not how many nodes are nearby. Checks 2 and 3 both depend on b, so they are tabulated together.

No singular solves, minimum ESS 15 against the 4 parameters the model needs, and the worst condition number 8.1e+04 — four orders below the danger line. 150 m is the sensible starting point: ESS 190 pools roughly a block in each direction while keeping the condition number at 2e+02. The manuscript specifies cross-validating b, so this is a starting value, not a choice.

4 · coefficients into elasticities

wk(s)=|βk|∑j|βj| normalising forces a + b + c = 1, the §2.7 constraint

This one is a specification question, not a feasibility one — and it is the only check of the four that does not pass cleanly.

The absolute value discards the sign. In a Cobb-Douglas, I+0.5 and I−0.5 move M in opposite directions. A dimension whose coefficient comes back negative — one that reduces dwell — is reported by this formula as one that matters a great deal, in the same direction as the others. If the fit ever returns a negative β, the normalisation hides exactly the finding that would be most interesting. Worth settling before the counts arrive.

What t_base would have to be

The manuscript defines it twice, differently. §2.7 says “detected pedestrian stayability counts from VLM vision processing”; §2.8 says “real-world localized pedestrian stayability counts from public data feeds and computer-vision sensor nodes”. Only the second makes this a test — the first regresses VLM output on VLM output.
